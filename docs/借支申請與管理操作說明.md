# 借支申請操作說明

更新日期：2026-10-22。適用版本：v1.34.0 起；正式使用前須確認安裝版本及管理部活動設定。

## 這個功能處理什麼

員工登記想預支的薪資金額，由管理部核准或退回。管理者可整理 Excel 總表，ERP 可讀取申請修訂資料。

核准不表示已發放款項，也不表示薪資已扣回。本功能不辦理付款、還款或直接修改 ERP 薪資。實際發放及扣回依公司的管理作業辦理。

## 首次活動設定

具「借支活動設定」權限的管理者，在「借支申請管理 → 活動設定」填寫：

- 每月開始日、截止日：初始為每月 15 日至 20 日，截止日包含當日，採臺北時間。日期可調整；月份沒有指定日期時使用該月最後一天。
- 單筆金額上限：填已確認的整數新臺幣金額，不能留空後啟用。
- 每月有效筆數上限：計入同月「待審」及「已核准」申請；已退回、撤回及取消不計。
- 預計扣回月份：可選申請當月、之後月份或「尚待確認」。不確定時留待確認，不能以此欄位代表款項已發放。
- 設定原因：留下設定或變更依據。

新功能初始停用，金額與筆數上限須由管理部確認並設定後才可啟用。活動設定適用之後送出的申請；既有申請保留送件時的設定快照。

## 員工操作

1. 以本人帳號登入並開啟「借支申請」。
2. 核對本月開放期間、金額與筆數上限。
3. 填入整數新臺幣金額，可加申請備註。
4. 按「送交管理部審核」。申請直接進入管理部待審清單，不需要主管審核。
5. 從月份篩選查看本人紀錄、審核結果及說明。

待審申請可按「撤回」並填原因。已核准的申請須聯絡管理部處理；員工不能自行改成未核准或直接刪除。需要改金額時，可在仍開放登記且符合筆數上限的情況下，撤回待審申請再送一筆。

此功能只供本人操作，指定代辦主管不能代填或查看其他員工的借支；身份模擬也不能操作。卡號登入與已設定個人網頁密碼登入均依本人的有效登入與裝置綁定驗證。

## 管理部審核及總表

在「借支申請管理」按月份查看，核對員工、申請金額與備註後，按「審核」。核准時填核准金額與說明；金額不可高於申請額。退回也需填說明。

待審或已核准申請可由具審核權限的人員「取消」並記錄原因。取消會保留原核准額與完整狀態歷史，並從目前有效核准總額排除；如果 ERP 已入帳，仍須另外在 ERP 核對更正，不會自動沖回款項。

「下載 Excel 總表及明細」會提供兩張工作表：

- 借支申請明細：單號、月份、工號、姓名、部門、狀態、申請與核准金額、時間及審核／取消說明。
- 總表：筆數、有效申請額、目前核准額及各狀態數量。有效申請額只計待審與核准；核准額只計目前仍核准者。

工號以文字匯出，前導零不省略。總表是申請核對資料，不能直接當作已發放清冊或薪資扣款憑證。

## 權限分開管理

管理部的查看、審核、活動設定、Excel 匯出各自有權限。請由帳號權限管理明確指定合適人員；擁有其他考勤管理或主管代辦權限，不等於可以讀取借支財務資料。

外部 ERP 使用獨立 `salary_advances` 讀取權限；原有 API Key 不自動取得此權限。啟用串接前應由開發者檢查金鑰範圍。

真正開發者原有的全域稽核紀錄、資料庫備份與維運權限仍可能接觸借支資料。這是高階維運權限的既有範圍，不表示開發者自動取得借支業務審核權；公司仍須限制哪些人可持有此高階權限。

## 常見狀況

| 畫面或訊息 | 處理方式 |
| --- | --- |
| 活動尚未啟用 | 管理部先完成金額及筆數設定，再確認啟用。 |
| 不在登記期間 | 核對臺北時間及當月設定；不接受偽造月份補送。 |
| 有效筆數已達上限 | 先查看待審／核准申請；不要重複送件。 |
| 申請已被更新 | 可能已由他人審核，重新整理後再核對；系統不覆蓋舊版本。 |
| 送出時網路中斷 | 保留原輸入再試；相同送件識別碼不會重複建單。重新載入後應先查看紀錄。 |
| 核准但沒有領到款項 | 核准是申請結果，請聯絡管理部確認實際發放作業。 |
| ERP 金額與申請不同 | 核對來源單號及修訂；已發放／已扣薪與申請金額屬不同階段，不應直接覆寫。 |
