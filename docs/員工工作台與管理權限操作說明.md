# 員工工作台與管理權限操作說明

更新日期：2026-10-22。適用版本：v1.35.0 起。

## 員工首頁的資訊

首頁把工號、姓名、部門、職稱、性別與國籍集中在同一個身分摘要；今日紀錄數、有效打卡、近 7 日紀錄、目前班別與下一次動作仍保留，改用緊湊的出勤摘要呈現。這次調整只有顯示方式，沒有刪除員工欄位、改寫打卡紀錄或改變統計口徑。

目前時間、日期、最後一次打卡及「現在打卡」按鈕放在一起。打卡仍依目前登入者、裝置與定位政策驗證；看到下一次預計動作不代表已完成打卡，送出後請核對結果。

工作台的請假、加班、午餐、借支、紀錄與個人資訊入口依可用寬度自動換列。手機使用較少欄數，無須沿著長橫向捲軸找功能。按入口後在下方開啟對應內容；主管代辦與審核入口仍只顯示給獲授權的人員。

## 自行調整入口順序

員工可以調整自己的順序，不必請管理者統一修改。

1. 用本人帳號進入員工工作台，按功能入口旁的「調整我的順序」。
2. 用每列的「上移／下移」按鈕，把常用功能移到前面；第一列不能再往上，最後一列不能再往下。
3. 按「儲存排序」後才保存至本人帳號。僅調整畫面而未儲存，不會改變已保存的順序。
4. 要回到系統預設，按「恢復預設」，再按「儲存排序」。預設把常用申請入口排在前面。

有未儲存的異動時按「關閉」，可選「繼續編輯」或「捨棄並關閉」；捨棄會保留原先已保存的順序。

順序儲存在服務主機，使用同一帳號在其他裝置登入也能取得。不同員工各自保存，不會改變其他人的畫面，也不會改變管理者／開發人員工作台的全域導覽順序。身份模擬只能查看，不能代員工保存個人偏好。

排序不會增加角色、授予資料權限或修改審核規則。未授權功能仍不可使用；新功能出現時，系統會補入可用入口，不必重新設定整份清單。

## 「一般管理者」與「完整管理者」的差異

舊版名為「完整管理者」的模板，實際沒有包含後來新增的網頁帳號、特休制度及借支等獨立管理權限。v1.35 起將這份舊模板改名為「一般管理者（既有模板）」，保留已授予的原權限，避免升級時讓既有帳號直接取得額外的密碼與財務資料權限。

新版另提供「完整管理者」，涵蓋目前全部管理者功能，包括網頁帳號、特休制度及借支管理。這是管理者功能模板，不會同時授予開發人員角色，也不會自動建立個人密碼或啟用管理登入。

| 選項 | 適用情況 |
| --- | --- |
| 一般管理者（既有模板） | 繼續沿用舊模板的功能範圍；不因這次升級自動增加獨立授權項目。 |
| 完整管理者 | 明確授權目前全部管理者功能，包括新增的獨立管理項目。 |
| 自訂權限 | 只開放工作需要的個別功能，例如借支查看與審核，無須授予全部管理功能。 |

## 讓指定帳號取得完整管理功能

1. 由有權限的人員開啟「帳號權限管理」，搜尋員工並按「設定」。
2. 核對「管理者」角色，選取新版「完整管理者」模板。
3. 核對下方實際權限，確認包含需要的網頁帳號、特休制度與借支項目，再按「儲存帳號權限」。只打開選單或選模板尚未保存。
4. 讓受影響人員重新登入，核對實際可見功能。首次使用管理工作台仍須設定個人網頁密碼，並由系統管理者／開發人員另行啟用管理登入。

完整管理者的網頁密碼權限仍僅能操作一般員工帳號，不能因此重設或查看管理者、開發人員或獨立系統管理者的密碼，也不能啟用管理登入。其他高階維運與角色管理依原本獨立權限控管。

借支的活動金額已確認為新臺幣 **15,000 元（1.5 萬元）**；實際生效上限以管理者自行儲存的活動設定為準。本次版面與權限模板更新不代替修改正式活動設定。詳見 [借支申請與管理操作說明](借支申請與管理操作說明.md) 與 [個人帳號與管理工作台登入說明](個人帳號與管理工作台登入說明.md)。
