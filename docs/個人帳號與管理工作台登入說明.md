# 個人帳號與管理工作台登入說明

日期：2026-10-21；適用版本：v1.33.0。

員工本人登入後，都能在上方找到「個人帳號」。是否已設定個人網頁密碼，不再影響按鈕顯示。個人密碼、主管代辦授權及管理工作台登入分開控管；設定密碼不會自動取得代辦、管理者或開發人員權限。

## 第一次自行設定

1. 使用自己的工號與原卡號登入員工工作台，依既有安全政策完成裝置驗證。
2. 按上方「個人帳號」。尚未設定密碼時，畫面會提供首次建立表單。
3. 輸入「目前卡號」、「新個人網頁密碼」與「確認新密碼」，按「建立個人網頁密碼」。卡號須符合目前員工資料；新密碼需為 8 至 128 字元，前後不可留空白，且不可與卡號相同。
4. 成功後依畫面提示重新登入，可使用原卡號或新個人網頁密碼。本人自行建立的密碼不需要再經一次臨時密碼更換。

首次設定只允許本人操作。卡號是現有登入身分的再次驗證，不是另一組獨立驗證因素；請保管卡號與密碼，不代替其他員工設定。身份模擬不能建立或修改被模擬者密碼。

## 已有密碼與忘記密碼

- 已有密碼時，「個人帳號」改顯示修改表單，須輸入「目前個人網頁密碼」、新密碼及確認新密碼。即使用卡號登入，也不能跳過目前個人網頁密碼驗證。
- 忘記個人網頁密碼時，請由具重設權限的人員在「個人網頁密碼管理」設定臨時密碼，再由本人使用臨時密碼登入並完成首次修改。卡號不能用來覆寫已建立的個人密碼。
- 密碼設定／修改／重設會撤銷受影響的原工作階段，請重新登入。原卡號、實體刷卡打卡與考勤紀錄不會變更。
- 設定個人密碼不會取消每人裝置上限或 GPS 等既有安全政策；重新登入仍依所進工作台及功能驗證。

## 指定主管使用卡號代辦

1. 有代辦設定權限的人員先在「主管指定」→「代辦主管」明確指定員工與主管；審核主管不會自動變成代辦主管。
2. 主管用自己的工號及原卡號，或個人網頁密碼登入員工工作台，進入「主管代辦」。主管不需要為此先設定／重設個人網頁密碼，被代辦員工也不需要。
3. 選授權員工與日期，填請假、加班或午餐內容，按表單要求填原因及核准確認。批量送件前核對實際勾選名單。
4. 送件後依原審核流程辦理。多主管／必審規則保留，不因卡號登入直接跳過審核；午餐仍受截止與結單限制。

每次讀取及送出會重新核對指定關係，撤銷後不能繼續代辦。操作保留實際主管、原因、時間及前後內容；身份模擬不可代辦。額度明細僅能查看已授權員工，不能因此調整額度。詳細步驟見 [主管代辦操作說明](主管代辦操作說明.md)。

## 管理者與開發人員另外啟用

進入管理者或開發人員工作台須同時具備：已指定的管理角色、已啟用的管理工作台登入，以及有效個人網頁密碼。卡號登入只進員工工作台；管理功能仍受各自權限限制。

1. 由本人登入的獨立系統管理者，或「開發人員工作台 → 系統設定 → 帳號權限管理」，開啟「個人網頁密碼管理」。開發人員畫面位於右側子頁內容，與帳號角色設定放在同一處，不會擠在工作台統計數字上方。
2. 在「管理工作台登入啟用」區的「管理工作台帳號」選人。只列已指定管理者／開發人員角色的人員；先確認姓名、工號與角色授權正確。
3. 若顯示「未設定密碼」，可先請本人自行首次設定，或依既有管理流程建立臨時密碼。新建密碼本身不啟用管理登入。
4. 輸入「驗證你的登入密碼」與「啟用／停用原因」（必填，最多 500 字元），按「啟用管理登入」或「停用管理登入」。獨立系統管理者使用自己的獨立密碼，開發人員使用自己的個人網頁密碼。
5. 異動會撤銷受影響的工作階段。啟用後本人重新以個人網頁密碼登入，才能選已授權的管理工作台；臨時密碼仍須先由本人完成修改。

只有真正登入的系統管理者或開發人員可以變更此啟用狀態。一般管理者即使被授予員工密碼重設權限，也不能啟用管理登入；身份模擬不可操作。這個開關不新增角色、也不放大角色內的功能權限。

## 升級與常見問題

| 問題 | 說明 |
| --- | --- |
| 升級後是否要全員重設？ | 不需要。既有密碼與卡號仍可使用；未設密碼者才使用首次設定流程。 |
| 已有管理者／開發人員會被鎖住嗎？ | 升級時既有個人網頁密碼保留管理登入啟用能力，仍須原本已指定角色；不自動授予新角色。 |
| 新版管理者替員工建立密碼，就能進管理工作台嗎？ | 不會。新建密碼預設管理登入未啟用，須另經上述啟用流程。 |
| 本人改密碼或管理端重設會改變管理登入狀態嗎？ | 不會，保留原啟用／停用狀態。重設後仍需完成臨時密碼修改。 |
| 登入後為何沒有主管代辦？ | 請核對是否有明確代辦指定、是否為本人登入，以及裝置驗證是否有效；不需先重設密碼。 |
| 啟用後仍沒看到管理工作台？ | 確認角色已指定、管理登入已啟用、以個人網頁密碼重新登入且已完成臨時密碼修改。卡號登入不提供管理工作台。 |
