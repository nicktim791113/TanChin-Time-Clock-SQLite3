# 資料庫備份與下載說明

適用版本：v1.30.0 起。更新日期：2026-10-19。

## 從 TC039 取得打卡鐘資料

在 TC039 瀏覽器開啟真正打卡鐘的網頁網址，使用具開發人員角色的帳號登入，進入「開發人員工作台 → 匯出設定 → 完整資料庫備份與還原」。

一次操作包含兩個步驟：**打卡鐘主機在本次選定位置建立完整備份，再由 TC039 的瀏覽器下載完整 ZIP**。TC039 不必安裝相同版本的程式才能下載；提供網頁與備份 API 的打卡鐘主機必須先更新至支援此功能的版本。

1. 核對上方兩個「已儲存路徑」。位置 1 保留原本打卡鐘的設定；未指定時使用主機資料目錄下的 `DatabaseBackups`。
2. 位置 2 初始值為 `\\Ts5600d494\oms\TanChin-Time-Clock-SQLite3 DB備份資料`，可以改成其他絕對本機或網路共用路徑，留空則停用位置 2。這個預設值會在新版未設定第二位置時顯示，不會改寫既有位置 1。
3. 修改路徑或保留份數後，先按「儲存備份設定」。儲存只驗證設定格式，不連線測試 NAS；實際備份時才檢查所選位置的存取權限。
4. 從「本次主機端存放位置」選位置 1 或位置 2，按「立即完整備份並下載」。只在所選位置建立一份主機端備份，不會同時寫入兩個位置。
5. 瀏覽器接手下載後，至 TC039 的下載清單／下載資料夾確認 ZIP。實際下載位置由瀏覽器設定決定，亦可能詢問另存位置；網頁不能直接指定 TC039 的任意磁碟資料夾。

操作期間按鈕會顯示忙碌，避免重複送出。同登入的工作台即時刷新會保留本次選擇及未儲存欄位；若欄位與已保存設定不同，系統會要求先儲存，不會用畫面上的新路徑執行舊設定。

## 各欄位與按鈕

| 欄位／按鈕 | 行為與注意事項 |
| --- | --- |
| 位置 1 · 已儲存路徑 | 顯示目前生效的打卡鐘備份位置；與尚未儲存的輸入分開呈現。 |
| 位置 2 · 已儲存路徑 | 顯示保存的指定位置；留空表示未設定。 |
| 位置 1 · 打卡鐘備份資料夾 | 保留原有路徑；清空後儲存則採主機資料目錄下 `DatabaseBackups`。 |
| 位置 2 · 指定備份資料夾 | 由打卡鐘主機寫入的第二路徑，初始為上述 NAS；可以修改或留空停用。 |
| 保留份數 | 3–3650 的整數，兩個位置各自依同一份數保留；執行備份時只清理當次寫入位置。 |
| 儲存備份設定 | 保存兩個路徑與保留份數，不會立即備份。 |
| 在主機選位置 1／2 | 在打卡鐘主機開啟原生資料夾對話框，並填入對應欄位；不是 TC039 的選檔視窗。遠端操作可直接輸入路徑。 |
| 位置 1 使用系統預設 | 清空位置 1 輸入，儲存後才生效，不會刪除舊備份。 |
| 本次主機端存放位置 | 僅選擇這次要寫入的位置，不更改排程預設或任務指定路徑。 |
| 立即完整備份並下載 | 建立主機端備份與完整 ZIP，隨即以目前登入權限下載到操作電腦。 |
| 再次下載這份備份 | 重試同一份已建立的 ZIP，不重新備份、不重新取樣資料庫。 |
| 還原備份檔／選擇備份檔 | 選目前連線主機可存取的、解壓後 `.db`／`.sqlite`／`.sqlite3`；不是瀏覽器上傳。 |
| 確認文字／還原資料庫 | 輸入「還原資料庫」後執行，會取代目前連線主機的資料庫；先建立還原前緊急備份。 |

## ZIP 內容及還原

下載包包含同一批次的資料庫 `.db`、`.manifest.json` 與存在時的 `.db.web-credentials.json` 密碼金鑰附檔。主機端所選資料夾仍保留原本的獨立備份檔與配套附檔；ZIP 下載暫存由系統管理。

還原前先**完整解壓縮 ZIP**，保持檔名不變，將配套檔案留在同一資料夾，再選擇 `.db`。不能直接將 ZIP 填入還原欄位。ZIP 不包含 `ThemeImages` 自訂背景或 `CustomSounds` 音效，需要完整重現外觀及聲音時另行備份這些資料夾。

若要在 TC039 試用正式資料，請先保留原始下載包，另外建立工作副本；核對 TC039 本機網址後才還原。正式資料庫內的自動化排程、備份與匯出路徑也會一起帶入，測試前應先停用或改成本機測試路徑。本次下載功能不會自動停用排程或產生測試專用資料庫，亦不會讓正式資料與 TC039 持續同步。

## 失敗、重試與常見疑問

- **主機端成功、瀏覽器下載失敗：**畫面會明確區分狀態。按「再次下載這份備份」可用同一包重試，不會重新建立備份。下載有效期為 15 分鐘，僅目前登入可用；到期、登出、重新登入、切換角色或服務重啟後，請重新執行完整備份。網頁重新整理會遺失僅存於記憶體的下載按鈕，主機端備份仍存在。
- **NAS 離線或權限不足：**選位置 2 備份會顯示失敗，不會悄悄改存位置 1。請檢查打卡鐘主機及其執行帳戶的 NAS 權限；TC039 自己能存取不代表主機也能寫入。位置 2 不會在開頁或存設定時被即時連線探測。
- **舊備份清理失敗：**新備份及下載仍可完成，畫面另提示保留份數清理警告；請處理被鎖定的舊檔或目錄權限。
- **列表沒有位置 2 的檔案：**「位置 1 最近完整備份」只列位置 1，位置 2 請至指定資料夾查看；清單讀取失敗會顯示錯誤，而不是假稱沒有備份。
- **排程會被改到位置 2 嗎：**不會。本次位置選擇只影響手動立即備份；既有任務有自己的輸出路徑就沿用，未指定時仍使用位置 1。
- **按下載後是否已確認磁碟存檔：**畫面只確認資料已交給瀏覽器，使用者仍須檢查下載清單、磁碟空間及瀏覽器限制。
- **誰能下載：**具開發人員角色的正常登入會話。身分模擬不能建立或下載完整備份；下載不可轉交其他登入使用，登入憑證不會放在網址。完整資料庫含個資及可用密碼金鑰，請勿公開分享或提交 Git。
