# 工作台指標與多主管審核

日期：2026-10-29；適用版本：v1.42.0。

## 九種卡片、畫面保留八張

工作台總覽提供九種分組卡，畫面固定顯示個人選定的八張；每張卡內的子項可分別點選。預設以「借支管理」替換「問候語與主題」，後者仍可從個人設定選回。桌機採四欄兩列，較窄畫面兩欄，手機單欄；不用橫向捲動尋找卡片。數字為真實服務資料，示意設計中的樣本數字不寫入系統。

| 卡片 | 完整內容 | 點選後的資訊 |
| --- | --- | --- |
| 人員與考勤 | 員工數量、今日正常打卡、今日異常打卡 | 名冊在職／離職／部門概況，正常／未打卡人員、異常紀錄及失敗稽核，可切換同卡子項 |
| 請假 7 日 | 前三天、今天、後三天，各日已核准人數 | 七日日期切換、全量人數／單數／申請時數、篩選及申請明細 |
| 請假待審核 | 待主管審核、待管理部複核 | 兩階段切換、全量待審概況、申請原因與多主管進度 |
| 加班 7 日 | 前三天、今天、後三天，各日已核准人數 | 七日日期切換、全量人數／單數／申請時數、篩選及申請明細 |
| 加班待審核 | 待主管審核 | 全量待審人數／單數／申請時數及明細 |
| 午餐團膳 | 今天份數、明天份數、今日生效參加人數 | 三子項切換、人員與部門概況、目前用餐及供應商交單狀態 |
| 班別與響鈴 | 班別數量、響鈴排程數量 | 目前班別、下一個響鈴、啟用狀態、完整配置清單，以及對應設定入口 |
| 借支管理 | 臺北時間當月待複核筆數、待複核人數、待複核金額及已複核金額 | 當月相同狀態範圍的人員／申請、金額、來源及版本；支援部門與人員篩選 |
| 問候語與主題 | 問候語數量、自訂主題數量 | 問候語內容與對象、主題／排程／特效概況，以及對應設定入口 |

七日卡用直條比較相對人數，深藍柱標示今天。柱高只代表該張卡七日內的相對人數，不代表工時或占全體員工的比例；數字與日期按鈕均可鍵盤操作。異常顯示紅色、待審橘色、正常打卡綠色；資訊仍有文字與數字，不單靠顏色辨識。

## 個人排列與高度

點「選擇卡片與排列」，每列選單可用尚未顯示的卡片替換該位置，始終保留八張不同卡片；再用往前／往後箭頭調整順序。第一列不能往前、最後一列不能往後。「標準」與「緊湊」調整間距與高度，兩種都保留卡片內全部資訊。「恢復預設」先改草稿；按「儲存排列與高度」才保存至目前帳號。關閉未儲存的變更時可選繼續編輯或捨棄。身份模擬禁止保存偏好。

既有八卡設定升級至 v3 時，保留其餘七張順序，只把原「問候語與主題」位置換為「借支管理」；v1 單項偏好先對應成分組，再套用同樣遷移。讀取不覆寫原設定，第一次儲存才寫入新格式。已存 v3 九選八之後尊重本人選擇，不再強制換回借支卡。兩視窗同時修改仍以修訂版本防止舊畫面覆蓋。

八張卡的標題與位置維持完整。未授權子項顯示「—」且不可點選，不會用零冒充無資料；整張都未授權時顯示說明。排列不會賦予額外資料權限；切換帳號或工作台會清除已開啟的明細狀態。

## 明細操作與統計口徑

- 日期或同卡子項按鈕：在同一彈窗切換項目，選取狀態會明確標示。切換項目會重設該項的明細篩選。
- 人員搜尋：輸入工號、姓名或部門片段，按「查詢」。部門下拉可與搜尋條件一起使用。「清除篩選」位於同一列並清除兩個條件。
- 彙總：依目前篩選計算完整符合資料的不同人數、單數與時數，不只計目前 50 筆頁面。人數卡片同人可能有多筆申請，明細單數可能大於卡片人數。請假／加班的「整張申請合計時數」包含每張申請的跨日時段，不應當作選定單日的扣假時數。
- 申請人：請假待主管審核、待管理部複核及加班待主管審核明細，將「人員」（請假／加班對象）與「申請人」分欄；申請人顯示記錄工號及名冊姓名。本人送件兩欄可相同，代辦則顯示實際代辦者。原始申請人工號缺失顯示「未記錄」，不猜成對象本人；有工號但名冊無姓名顯示「姓名未記錄」。
- 申請內容：展開查看原因，以及可用的多主管必審、核准、駁回與意見資訊。此彈窗用於查閱，實際審核仍在原請假／加班作業頁執行。
- 分頁：請假、加班、午餐、借支明細每頁 50 筆；頁尾顯示目前範圍、符合總數、篩選前總數及上下頁。切換頁面保留篩選條件。
- 系統設定類資訊：先顯示配置概況與完整清單，再由「開啟班別設定／響鈴設定／問候語管理／主題編輯器」直接進入對應作業頁；不在資訊彈窗裡放隱含保存動作。
- 重新讀取失敗：保留錯誤說明並提供重新讀取按鈕。工作台更新會同步更新開啟中的明細；跨日舊日期查詢會拒絕並提示重新整理。

請假／加班每天只計已核准、同一員工不重複計人。日期依台北時間前後三天處理跨月／跨年；請假有每日實際時數時只計正時數日期，舊單無每日分配時依起訖區間判定，結束時間不包含在區間內。待審核計全部日期的申請單數，不受最近資料列表或員工歷史可見月數限制；多主管單仍只計一單。

午餐目前份數不等於交單份數，未交單也不等於零份。參加團膳人數依今日生效資格，不等於今日用餐數。點今天／明天可見供餐狀態及已交單總份數，明細區分目前用餐與已交單用餐；此功能不是領餐或餐費結算。

借支卡依臺北時間當月登記月份統計；同人多筆待複核分別計筆、人數去重。已複核金額包含仍有效的紙本補登，排除退回、撤回及取消，不代表已發放或已扣薪。明細以目前篩選完整集合計數及加總，不只計當頁；跨月舊卡查詢會要求重新整理。只有現有借支查看、複核、紙本、活動設定或匯出任一權限才讀取財務資料；未授權或身份模擬顯示「—」，不因排列選擇取得權限。

## 出勤統計範圍

正常／異常打卡明細內的「出勤統計範圍」可選全部、在職、指定部門或手動員工，並顯示納入統計人數。這是原瀏覽器的顯示偏好，不限制員工打卡，也不改權限、請假、加班或團膳統計。員工數量始終為名冊總數，不跟著出勤篩選縮小。正常人數與異常筆數不是同一種單位，不能直接加總為全體人數。

## 多主管與主管提示

在「主管指定 → 主管審核」多選員工與主管，再選任一核准或指定必審；詳細步驟、代辦例外與升降版風險參照 `docs/主管審核個別指定說明.md`。審核授權不等於代辦授權。

主管以本人帳號進員工工作台，上方顯示「待我審核」及請假／加班分項，可直接進對應審核日曆。只計此人尚有票權且尚未決定的案件；部分核准後其他必審者仍看得到。舊單保留原主管，不依新設定改派。
