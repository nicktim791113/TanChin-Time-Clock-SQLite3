# TanChin-Time-Clock-SQLite3 更新紀錄

這份文件用來保存每次功能優化、錯誤修正、資料結構調整、操作流程變更與備份流程異動。之後每次完成修改後，都要在這裡追加一筆紀錄，並且每次核心資產備份都會把這份文件一起打包。

## 備份指令

在專案根目錄執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\backup-core-assets.ps1"
```

預設備份輸出位置：

```text
C:\Users\nickt\OneDrive\Developer 公司系統\TanChin-Time-Clock-SQLite3 原始資料
```

備份內容包含：

- 專案原始碼與設定：主程式、瀏覽器端、桌面端、資料庫模組、匯出模組、package 設定。
- 視覺與介面資產：assets、icon、modals、browser-client、renderer-scripts。
- 開發文件、自動測試與文案：docs、tests、根目錄 txt/md 文件、研發提示語等。
- 備份工具本身：scripts。
- 營運核心資料：`%APPDATA%\TanChin-Time-Clock-SQLite3\app_data.db` 與相關 SQLite 檔。
- 使用者自訂素材：CustomSounds、ThemeImages、AuditArchives、logs。

不包含：

- `node_modules`
- `dist`
- Electron/Chromium 快取資料，例如 Cache、Code Cache、GPUCache、Network、Session Storage。

## 2026-10-22 / v1.34.0

### 多日期與時段請假

- 同一假別可在一張單中加入多個不連續日期與各自起訖時段；可從日期區間展開每日時段，也可同日新增不重疊時段。實際時數逐段填寫並加總，沿用指定主管與管理部終審流程。
- 新增獨立時段表與穩定時段 ID；額度、精確重疊檢查、日曆、考勤報表、打卡警示及午餐提醒依實際時段處理。原連續區間與逐日舊單保留原語意，不自動猜測舊單每日時間。
- 本人、授權主管代辦、紙本補登與修正共用時段資料；新請假模式不可直接交給不識別時段的舊版繼續寫入。

### 借支申請與 ERP 交接

- 新增員工「我的借支」及管理者「借支管理」：本人登記、撤回；管理部直接審核、退回、取消與下載 Excel 總表／明細，不經主管審核、不開放主管代辦。
- 每月活動預設日期為 15～20 日，開始日、截止日、金額上限、有效筆數與預計扣回月份均可調整。金額及筆數尚未確認時保持未設定及停用；啟用前須完成設定。每筆保留送件規則快照，核准金額不能超過申請金額。
- 查看、審核、活動設定與匯出分開授權，既有一般管理者及外部 API Key 不自動取得借支權限。本人及管理異動有稽核與版本衝突檢查，送件可安全重試。
- 新增唯讀 `/api/salary-advance-requests`，需 `salary_advances` 權限；提供修訂事件與取消紀錄、分頁游標及事件識別驗證。核准不是發放或扣薪；ERP 接收端修改、入帳與鎖期核對交由 ERP 代理依交接文件完成。

### 文件、驗證與部署

- 更新頁內說明、完整手冊、操作與部署文件、ERP 接手提示詞；新增借支後端模組納入核心備份。

## 2026-10-19 / v1.31.0

### 新增

- 跨日請假提供逐日勾選、每日實際時數、批量套用與總時數自動加總。依使用者選擇，跨日預先勾週一至五；週六日可自行勾回，國定假日可取消。單日不因週末自動排除；系統未串接公司排班或國定假日表。

- 修正跨日考勤以整段經過時間平均分配造成假日列計；新版直接採每日實際時數，查單一日不會將整筆時數再次分攤。七日明細區分當日時數與整筆時數。

- 每日資料與請假單、批量送件、紙本修正、額度、精確帳本及稽核同交易；權限與審核流程維持原規則，員工仍只操作本人、主管限明確授權員工。
