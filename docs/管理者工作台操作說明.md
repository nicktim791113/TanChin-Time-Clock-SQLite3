# 管理者工作台操作說明

適用版本：v1.28.0（2026-10-17）。

每個主頁與子頁均有「操作說明」，頁首「本頁說明」開啟同一頁指南。欄位清單依目前權限與實際顯示內容整理；人員列重複按鈕合併說明，不列員工個資。無資料或無操作權限時，相關列按鈕不顯示。

八張指標與明細參照 [工作台指標與多主管審核說明](工作台指標與多主管審核說明.md)。本文件與頁內說明均應隨新增欄位、按鈕及流程更新。

## 新增／編輯員工

維護員工主檔。新增與編輯使用同一表單；編輯時會帶入既有資料，儲存才會寫入。

1. 先填工號、姓名、部門及班別，再核對卡號與任職資料。
2. 感應讀卡只填入卡號，不會產生打卡紀錄。完成後按儲存；取消編輯可回到新增狀態。
3. 聯絡、家庭、銀行與身分資料屬個人資料，僅填業務所需。

- 改工號前先確認歷史與關聯資料；不要用刪除再新增代替一般資料修改。
- CSV 匯出包含完整名冊，不受篩選影響；匯入按工號／卡號合併，不刪除未列出的員工。

| 欄位／按鈕 | 用途與影響 |
| --- | --- |
| 工號 | 員工或設定的唯一識別碼；編輯時先核對對象，避免以新代碼重建既有資料。 |

## 部門設定

部門清單供員工主檔與篩選選用。主管審核另在「主管指定」維護。

1. 填部門名稱與排序，確認啟用狀態後儲存。
2. 清單的編輯會帶入表單；停用或刪除前先確認仍使用該部門的人員。

- 停用不等於刪除員工，也不會自動重新指派主管。

| 欄位／按鈕 | 用途與影響 |
| --- | --- |
| 部門名稱 | 此筆人員或設定的顯示名稱。 |
| 排序 | 清單排序數值。 |
| 說明 | 此設定的用途或補充說明。 |
| 啟用 | 是否啟用此設定；停用與刪除不同。 |
| 儲存部門設定 | 送出目前表單。先核對對象、必填欄、原因及確認欄；以成功訊息確認完成，失敗時依提示修正。 |

## 員工名冊資料

查找人員、選擇顯示欄位，或進入個別主檔編輯。

1. 以搜尋文字、部門等條件縮小名單；清除篩選恢復全部。
2. 顯示筆數控制畫面高度；表頭欄位設定只改顯示，不刪除資料。
3. 按編輯進主檔；刪除須先核對工號。審核與代辦主管統一從上方「主管指定」進入。

- 匯出 CSV 是完整名冊，不等於目前篩選結果。
- 名冊人數與出勤統計範圍不同；統計範圍在指標明細內設定。

## 遠端打卡規則

設定瀏覽器打卡的裝置綁定與 GPS 驗證條件。

1. 選擇是否要求裝置綁定與 GPS，填允許定位誤差。
2. 核對設定後儲存；員工下次登入／打卡時按目前政策檢查。

- GPS 誤差上限是定位精度條件，不是公司地址的距離圍欄。
- 裝置資料或 GPS 不等於工作時數；打卡結果仍應配合考勤查核。

| 欄位／按鈕 | 用途與影響 |
| --- | --- |
| 啟用裝置綁定 | 要求員工遠端登入／打卡使用符合綁定政策的裝置。 |
| 打卡必須 GPS | 遠端打卡時要求提供 GPS；瀏覽器仍須取得定位權限。 |
| 允許 GPS 精度上限（公尺） | 允許的定位誤差上限，單位公尺，並非地理圍欄半徑。 |
| 儲存安全設定 | 送出目前表單。先核對對象、必填欄、原因及確認欄；以成功訊息確認完成，失敗時依提示修正。 |

## 裝置綁定清單

依員工分組查看綁定裝置，並安全解除指定範圍的綁定。

1. 用關鍵字、部門與綁定狀態查找員工；清除篩選只重設查詢。
2. 解除單一裝置只影響該裝置；「解除此人全部裝置」只影響該工號。
3. 確認窗先核對受影響裝置，再按要求輸入工號確認；取消不會異動。

- 解除此人全部裝置不是清除全體員工。重新登入能否再次綁定，仍由當時安全政策決定。
- 如果確認期間裝置清單已變動，請重新載入並再次核對。

| 欄位／按鈕 | 用途與影響 |
| --- | --- |
| 搜尋人員 / 裝置 | 縮小目前清單的顯示範圍，不會刪除資料或自動勾選人員。 |
| 部門 | 按部門縮小清單；全部部門表示不限制。 |
| 綁定狀態 | 選全部、已綁定或未綁定人員；不會新增或解除綁定。 |
| 清除篩選 | 清除目前查詢條件並恢復預設範圍，不刪除業務資料。 |

## 最近遠端打卡

以人員彙總最近兩週遠端打卡，再按需要查看明細。

1. 期間採台北時間今天及前 13 日；人員列彙總期間內的紀錄。
2. 先篩選人員，再開啟該員工明細，核對時間、結果、來源與風險資訊。

- 最近兩週不受舊有 50 筆上限截斷。已刪除員工的歷史仍保留並標示。
- 彙總筆數是紀錄數，不能直接當作出勤天數或工作時數。

| 欄位／按鈕 | 用途與影響 |
| --- | --- |
| 搜尋人員 | 縮小目前清單的顯示範圍，不會刪除資料或自動勾選人員。 |
| 部門 | 按部門縮小清單；全部部門表示不限制。 |
| 風險狀態 | 選全部、有風險或無風險的兩週人員彙總。 |
| 清除篩選 | 清除目前查詢條件並恢復預設範圍，不刪除業務資料。 |

## 員工網頁打卡權限

控制哪些員工可從瀏覽器打卡；不修改實體卡片或既有考勤。

1. 搜尋並勾選員工，選允許或禁止網頁打卡。
2. 填異動原因，檢查批量對象與確認欄後儲存。

- 未設定例外時依現有預設政策處理；不要把畫面篩選當成已勾選名單。

| 欄位／按鈕 | 用途與影響 |
| --- | --- |
| 允許線上打卡的員工搜尋 | 縮小目前清單的顯示範圍，不會刪除資料或自動勾選人員。 |
| 允許線上打卡的員工部門 | 篩選此人員選取器的部門，不自動勾選，也不移除先前已選人員。 |
| 選取顯示 | 勾選目前篩選後顯示且可選的人員；核對已選人數，不代表整個名冊。 |
| 清除 | 清除此選取器的已選人員，不刪除員工或已保存的設定。 |
| 選擇員工 | 勾選以納入「選擇員工」；在確認及儲存前核對本次選取範圍。 |
| 允許線上打卡的員工名單高度 | 調整允許線上打卡的員工名單高度；拖曳滑桿或使用方向鍵，觀察畫面變化。 |
| 設定原因 | 本次申請或異動原因，保存後供審核與稽核使用。 |
| 確認更新員工網頁打卡權限 | 核對上方對象、內容及影響後才勾選；未勾選不能送出。 |
| 儲存網頁打卡權限 | 送出目前表單。先核對對象、必填欄、原因及確認欄；以成功訊息確認完成，失敗時依提示修正。 |

## 員工紀錄可見範圍

1. 分別設定請假與加班可回看月數，填原因並確認儲存。

- N 代表本月加前 N 個月，0 仍可看本月；不限制代表不裁切。
- 此設定不刪除資料，不改管理者查詢或員工額度扣抵；主管授權另受權限管控。

| 欄位／按鈕 | 用途與影響 |

| 請假回看月數（本月另計） | N 表示本月加前 N 個月；0 仍包含本月，不限制則完整保留可見範圍。 |

| 加班回看月數（本月另計） | N 表示本月加前 N 個月；不影響管理者查詢及額度計算。 |
| 設定原因 | 本次申請或異動原因，保存後供審核與稽核使用。 |
| 確認更新全體員工的紀錄可見範圍 | 核對上方對象、內容及影響後才勾選；未勾選不能送出。 |
| 儲存紀錄可見範圍 | 送出目前表單。先核對對象、必填欄、原因及確認欄；以成功訊息確認完成，失敗時依提示修正。 |

## 手動補登

## 考勤報表 — 查詢條件 / 匯出

依日期與員工查詢考勤，再匯出與目前查詢一致的結果。

1. 選起訖日期與員工，按查詢報表。
2. 查看摘要與考勤明細，再選精簡考勤 CSV 或請假／加班明細 CSV。
3. 重設條件會清除查詢狀態；更改條件後須重新查詢才是新的結果。

- 薪資明細列核准請假／加班時數，不代表系統已計算應付薪資。
- 資料頁的欄位顯示與匯出模板是不同設定。

| 欄位／按鈕 | 用途與影響 |
| --- | --- |
| 員工範圍 | 選擇本次操作的員工；送出前核對工號與姓名。 |
| 開始日期 | 此設定的生效起日。 |
| 結束日期 | 此設定的適用迄日。 |
| 查詢報表 | 依目前條件重新取得資料；核對結果的期間與筆數。 |
| 重設條件 | 清除目前查詢條件並恢復預設範圍，不刪除業務資料。 |
| 匯出精簡考勤 CSV（舊薪資格式） | 依目前查詢範圍與所選模板匯出 CSV；下載後核對日期、人員及欄位。 |
| 匯出薪資請假／加班明細 CSV | 依目前查詢範圍與所選模板匯出 CSV；下載後核對日期、人員及欄位。 |

## 明細與確認視窗

指標排列、指標明細與裝置視窗皆有獨立操作說明，可在視窗內開啟；按 Esc 或關閉返回原視窗。

### 指標排列與高度

八張卡保留固定資訊群組，可調整個人排列順序與顯示高度。

1. 逐列用向上／向下按鈕調整順序，選擇顯示高度並查看預覽。
2. 確認設定後儲存；關閉若有未存內容，可繼續編輯或捨棄。

- 設定只影響目前帳號的呈現，不改統計資料或其他管理者。
- 舊單項設定轉換為八個群組；請依遷移提示核對並保存。

### 指標明細與統計範圍

核對卡片的統計口徑、彙總與人員明細，再進入有權限的設定。

1. 七日卡可切換日期；待審卡可切不同審核階段。
2. 以人員關鍵字及部門縮小清單，查詢後核對總數與分頁。
3. 出勤統計範圍可選全部、在職、部門或手動人員；設定頁入口另以按鈕標示。

- 每日人數是當日不重複員工，跨日同一人可能出現在多日，不可直接相加當七日不重複人數。
- 待審依申請件數；正常打卡依人數，異常打卡含紀錄與失敗稽核，不能將不同口徑相除當出勤率。
- 沒有權限顯示不可查看，不應當作零；篩選不修改原始紀錄。

### 裝置明細與解除確認

查看一位員工的裝置及最近使用情形，只解除已核對的指定範圍。

1. 先核對裝置名稱／ID、平台、綁定與最後登入時間、IP 及 GPS 資訊。
2. 解除此裝置只處理單一裝置；危險操作區的解除全部只限這位員工。
3. 確認頁列出受影響裝置；勾選影響確認，全部解除另需輸入該工號，再按確認解除。
4. 返回裝置清單或關閉不執行解除；確認期間名單已變動會拒絕，重新檢查後再操作。

- 解除綁定不刪除打卡歷史，且不會清除全體員工。
- IP、GPS 及最後使用時間是當時記錄，不表示裝置現在的位置。

### 遠端打卡個人明細

查看該人最近兩週的完整遠端打卡紀錄。

1. 核對期間、時間、上下班類型、考勤狀態與裝置。
2. 逐項查 GPS／精度與風險資訊，關閉回到人員彙總。

- 風險標記供查核，不直接認定違規或計算薪資。
- 紀錄數、出勤日數及裝置數有不同口徑。

## 清單列操作補充

- 編輯：把所選項目載入表單，儲存前不異動原資料。
- 刪除／清空歷史：先確認所屬資料與影響範圍。
- 清空／重設表單：恢復新增／初始狀態並捨棄未儲存的輸入，不刪除已儲存資料；清除篩選只重設查詢條件。
- 核准／駁回：先核對對象、票權與備註；必審案件需按全部指定主管的進度判定。
- 修正／作廢：限具權限的適用紀錄；修正維持同一單號並保存稽核，作廢記錄原因。
- 啟用／停用：切換設定是否生效，不刪除歷史。
- 分頁：上一頁／下一頁只切資料視窗；總筆數與目前頁筆數不同。
