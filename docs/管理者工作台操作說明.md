# 管理者工作台操作說明

## v1.45.0 考勤報表整合（2026-10-30）

「考勤報表」把原本的查詢條件／匯出、查詢摘要及考勤明細整合為一頁，不需切換三個子頁。上方選全部員工或單一員工及起訖日期，按「查詢報表」後直接向下核對摘要和明細。

下方摘要、明細及兩種匯出均採最後一次成功查詢的員工／日期範圍。只修改欄位還未查詢時，原結果保持；「重設條件」會清除查詢結果。未查詢及無資料有明確提示。

「匯出精簡考勤 CSV（舊薪資格式）」保留固定九欄；「匯出薪資請假／加班明細 CSV」沿用已核准請假及加班明細規則。格式差異可在查詢區展開查看。此版只整合畫面，不改出勤、核准、原資料範圍、匯出格式或 ERP 規則。

適用版本：v1.45.0（2026-10-30）。

## v1.43.0 員工個別查詢與裝置設定

安全設定可分別調整各員工「最近打卡紀錄」的查詢範圍：最近 7 日（預設）、本月、本月及上月。依台北日期界線至現在時間限制本人資料；首頁近 7 日摘要不因範圍擴大而改口徑。這與全域請假／加班的紀錄範圍分開設定。

個別裝置上限可選「沿用全域」或 1～4 台，畫面顯示實際有效上限及已綁數。調低不刪裝置，既有有效憑證仍可登入，只阻止超額新綁定；P213 與診斷按有效上限判斷。不能用提高上限代替核對遺失憑證或解除錯誤綁定。

具 `admin.security.manage` 或系統管理者權限才可儲存，具 `admin.security.view` 可唯讀。修改後填原因並確認儲存；兩個設定表單各自提交，舊修訂版本須重新整理後核對再送出，不強制覆蓋另一視窗。身份模擬禁止儲存，員工不能查看全員設定。個別設定保存 SQLite，與稽核同交易；刪除工號同步清除，工號重用恢復預設。

主管多人紀錄查詢、每頁 50 筆與對象明細見 [主管代辦操作說明](主管代辦操作說明.md)。員工手動上／下班與確認限制見 [員工工作台說明](員工工作台與管理權限操作說明.md)。本次正式服務尚未部署，操作驗收依交付結果另行核對。

v1.42.0：「請假待審核」的待主管／待管理部兩項，以及「加班待審核」明細新增「申請人」工號與姓名；原「人員」是請假／加班對象，代辦者另列。缺失申請人工號顯示「未記錄」，不以對象補值。主管代辦的試填、時數計算與常用原因管理見 [主管代辦操作說明](主管代辦操作說明.md)；身份模擬只能查閱與試填，不能送件或保存設定。

每個主頁與子頁均有「操作說明」，頁首「本頁說明」開啟同一頁指南。欄位清單依目前權限與實際顯示內容整理；人員列重複按鈕合併說明，不列員工個資。無資料或無操作權限時，相關列按鈕不顯示。

九種卡片中選八張顯示；預設新增「借支管理」，可在「選擇卡片與排列」換回問候語與主題、排序及調整高度。指標與明細參照 [工作台指標與多主管審核說明](工作台指標與多主管審核說明.md)。本文件與頁內說明均應隨新增欄位、按鈕及流程更新。

往下捲動頁面時右下角顯示「回到最上方」，只捲動畫面，不保存或清除表單。

## 借支管理

具借支權限者選「借支管理」，標題及操作說明位於工作台總覽指標下方的內容區；左側提供「查看登記月份」、「管理部待複核」、「紙本核准補登」、「活動設定」，依各自權限顯示。此功能不經主管；新版完整管理者模板涵蓋目前管理功能，但既有帳號須明確重新授權，升級不自動加權限。

1. 活動設定可調整開始／截止日（預設每月 15～20 日）、金額上限、每月有效筆數、預計扣回月份及啟用狀態，填寫原因後儲存。未確認金額／筆數前保持停用；設定只影響新申請。
2. 「查看登記月份」是唯讀全員名冊，以月份、人員、部門及狀態篩選；無申請灰色、待複核黃色、已取消／已退回紅色、已複核／補登記綠色，申請狀態旁附金額。每人一列以最新一筆狀態篩選，更新日期獨立欄位；點人員展開歷次及單號，上方可全部展開／收合。「有申請紀錄」排除無申請者。
3. 「管理部待複核」保留月份明細與總額；審核或取消在當前畫面開彈窗。核准金額不能超過申請額；核准與退回說明選填，取消原因仍必填。已被其他人更新時先重新整理。
4. 「紙本核准補登」每人緻密單列：工號／姓名、本月狀態、編輯紀錄與版本、金額、備註、儲存及更新日期。編輯選單包含單號，不另佔一欄；在人員列填金額與選填備註並確認儲存；儲存後可更正原筆，保留單號、增加修訂並留前後操作紀錄。員工本人的「查看登記月份」同步顯示。紙本可補登歷史月份，但仍有設定金額及有效筆數限制；更正沿用該筆原始金額上限與扣回月份。
5. 選月份下載 Excel 明細及總表；總表核准額排除已取消資料。查看、審核、紙本補登、設定及匯出分開授權，員工只能看本人資料，指定主管不能代辦借支。已核准不等於已發放，取消或更正也不會自動沖回 ERP 已發款項。

查詢、待複核及紙本三頁都有四張對應指標，置於借支標題列正下方、內容篩選列之前。查詢與紙本按目前篩選人員統計；待複核指標表示當月完整總量。

完整欄位及例子見 [借支申請與管理操作說明](借支申請與管理操作說明.md)；ERP 代理使用 [串接交接說明](ERP借支串接交接說明.md)。

## 午餐全員參加資格

午餐日曆首次進入直接載入臺北時間當月。參加資格上方為篩選列，下方列出全部員工（包含未設定者），分開顯示目前參加、生效日期、最近修改日期、未來預定異動與歷次設定。按該員工「加入／不加入」才開啟彈窗；修改日期唯讀且以儲存當下記錄，生效日期預設下月 1 日，可改今日或未來，原因必填。伺服器檢查版本避免覆蓋他人變更；詳見 [午餐團膳操作說明](午餐團膳操作說明.md)。

## 多時段請假

同一假別可加入不連續日期及各自起訖時段；同日可新增多段。整單加總並沿用原審核規則，主管與管理部核對展開的實際時段，不能只看外層最早／最晚日期。紙本補登及授權代辦共用此方式，舊單保留原日期模式。詳見 [請假操作說明](跨日請假逐日選擇操作說明.md)。

## 個人帳號與管理登入

- 員工本人登入後皆可從上方「個人帳號」自行首次設定個人網頁密碼，須輸入目前卡號驗證；已有密碼者仍須目前個人網頁密碼才能修改。忘記密碼才使用授權重設流程，不需要全員先請管理者設定。
- 指定代辦主管可用本人原卡號或個人網頁密碼進員工工作台代辦；只限明確授權員工，保留原審核、截止及稽核，身份模擬不可操作。
- 新版新建的個人密碼預設不啟用管理者／開發人員工作台。真正登入的獨立系統管理者或開發人員，在「個人網頁密碼管理」→「管理工作台登入啟用」選已指定管理角色的人員，輸入自己的目前登入密碼及原因，再按「啟用管理登入」／「停用管理登入」。
- 一般管理者的「重設一般員工網頁密碼」或查看密碼權限，不能代替管理登入啟用權限。升級時既有個人密碼保留管理登入能力，仍受原角色及功能權限限制；本人修改或管理端重設保留原啟用狀態。
- 開發人員入口在「開發人員工作台 → 系統設定 → 帳號權限管理」右側內容區，密碼管理與管理登入啟用放在同一子頁；不再顯示於工作台統計數字上方。
- 啟用／停用後受影響的人員需重新登入。完整欄位、首次設定與錯誤排查見 [個人帳號與管理工作台登入說明](個人帳號與管理工作台登入說明.md)。

## 新增／編輯員工

維護員工主檔。新增與編輯使用同一表單；編輯時會帶入既有資料，儲存才會寫入。

1. 先填工號、姓名、部門及班別，再核對卡號與任職資料。
2. 感應讀卡只填入卡號，不會產生打卡紀錄。完成後按儲存；取消編輯可回到新增狀態。
3. 聯絡、家庭、銀行與身分資料屬個人資料，僅填業務所需。

- 改工號前先確認歷史與關聯資料；不要用刪除再新增代替一般資料修改。
- CSV 匯出包含完整名冊，不受篩選影響；匯入按工號／卡號合併，不刪除未列出的員工。

## 部門設定

部門清單供員工主檔與篩選選用。主管審核另在「主管指定」維護。

1. 填部門名稱與排序，確認啟用狀態後儲存。
2. 清單的編輯會帶入表單；停用或刪除前先確認仍使用該部門的人員。

- 停用不等於刪除員工，也不會自動重新指派主管。

| 部門名稱 | 此筆人員或設定的顯示名稱。 |

## 遠端打卡規則

設定瀏覽器打卡的裝置綁定與 GPS 驗證條件。

1. 選擇是否要求裝置綁定、每人裝置上限（1～4 台）與 GPS，填允許定位誤差。
2. 核對設定後儲存；員工下次登入／打卡時按目前政策檢查。

- GPS 誤差上限是定位精度條件，不是公司地址的距離圍欄。
- 裝置資料或 GPS 不等於工作時數；打卡結果仍應配合考勤查核。

| 欄位／按鈕 | 用途與影響 |

## 裝置綁定清單

### 特休制度版本

建立可追溯的制度與小數規則，保存舊版本供每筆給假重算。

1. 填制度名稱、生效日與特休假別代碼；假別須啟用並扣額度。
2. 選曆年或週年；曆年可另選半年假整筆給、年底結清，滿一年後仍採所選比例及小數規則。
3. 填協商／制度依據及原因，逐項確認後建立版本。

- 新生效日須晚於既有版本，不能回溯覆蓋已發給來源。
- 進位在精確分段加總後只做一次；7.01 變 7.1，精確 7.1 不變 7.2。
- 全薪／半薪標記不參與特休權利計算，本功能不計薪或付款。

### 年資核對與期初接管

確認真正受僱年資、工時與期初餘額，避免漏給或與人工額度重複。

1. 選員工，核對名冊到職日與認列年資起算日。
2. 填正常工時、工作型態及必要的比例依據；不計年資區間每列填起日、復職日、原因。
3. 填接管起日、接管日前未休剩餘小時、期限與對帳來源；接管前權利不再重複自動發給。
4. 月底／閏日等日期人工核對後勾確認；保存核對版本及原因。後續服務修訂只影響適用版本，不改寫已入帳快照。

- 不計年資區間採起日含、復職日不含，不可重疊。
- 每週工作日相同、每天較短者維持完整日數；比例型工時不能再重複折減每日工時。
- 名冊或人工額度在核對後異動時需重新核對；已發權利不能以改到職日直接回寫。

### 年資特休試算與核准

先計算、再核對、最後確認入帳；未取得的未來權利清楚分開顯示。

1. 選制度、配置年度及資格基準日，填原因。
2. 用工號／姓名或部門篩選並選取 1 至 100 位員工；篩選不會取消已選人員。
3. 產生試算後展開每人與各來源，核對法定級距、資格日、年資排除、分攤權重、精確原值、進位差額及後續年度配置。
4. 全部待確認項目處理完，具給假權限者勾確認後核准入帳；舊預覽、未來基準日及重複請求會受檢查。

- 半年 3 日與滿一年 7 日是獨立權利，不只補 4 日。
- 只有已取得事件入帳；未達資格日的試算沒有可用額度。
- 同一員工資格事件只給一次，確認失敗時整批回滾。

| 來源計算步驟 | 展開查看年資門檻、原資格日、不計年資日數、調整後資格日、法定級距、工時比例及基準日資格。 |
| 年度分段與折算 | 逐段列起日、迄日（不含）、完整來源權重、年度交集權重、分攤比例、原始日數／分數、小時及公式。 |
| 本次各年度配置 | 逐年核對本次來源配置小時與期間；須連同所選年度一起檢查。 |

例如一筆來源已完整取得 80 小時，其中 52 小時配置於所選年、28 小時配置於次年；確認會保存完整來源與兩年配置。不得把 80 小時都當所選年餘額，也不得將 28 小時當成未取得預估。以上是示意，實際以試算明細為準。

分次給假會依累計原值重新核對進位，僅入帳差額；不每次重複進位加給。若先前進位部分已使用，系統保留已使用來源並調整尚可用的新來源，不讓既有請假失去扣抵來源。

### 年度結算與協商遞延

逐來源核對未休餘額；結轉保留來源，工資項目維持待核定狀態。

1. 選來源年度、基準日及年度終結／契約終止情境。
2. 展開來源並勾選本次處理；待審預占與每日分配異常須先結案。
3. 協商遞延須逐筆填同意日期與證據；其餘列待未休工資處理。
4. 預覽核對來源扣除與轉入結果，再由結轉權限確認；離職須涵蓋全部已取得來源，包括後續年度配置。

- 結轉不是兩個年度都保留完整可用額度，之後先扣遞延來源。
- 已遞延批次不能再次遞延；已離職者也不能以年度情境繞過工資結算。
- 待未休工資不是已核薪或已付款；本版不執行薪資付款。
- 舊單撤回會回到原來源，若來源已結算，需重新核對新增剩餘，不自動加到下一年。

| 欄位／按鈕 | 用途與影響 |
| --- | --- |
| 結算來源年度 | 試算的配置年度或結算的來源年度；離職結算年度應與結算基準日一致。 |

年度終結只列所選來源年度；契約終止先選人員，列出其全部已取得來源，包含已配置到後續年度的部分。離職結算年度依基準日自動帶入。未到期且未離職不能結清；已離職者不能改選年度終結來繞過不得遞延的限制。

### 精確特休額度調整

用獨立額度管理權限作差額修正，保存原始給假與完整異動。

1. 選員工來源批次，確認其可用、已休、預占及結算情況。
2. 填正或負的精確小時，接受十進位或分數，例如 -0.125、1/3，並填原因。
3. 預覽前後差額，核對後確認調整。

- 負調整不能移除已使用、預占或已結轉的權利。
- 查看、給假或結轉權限不等於額度調整權限。
- 修正保留原批次與異動紀錄，不刪除原請假單。

| --- | --- |
| 調整來源批次 | 選擇本次調整的精確來源批次，不直接覆寫整人全年餘額。 |
| 精確調整小時（可正／負） | 正數加額度，負數減尚未使用的額度；單位小時，支援小數或分數。 |

| 確認精確調整 | 確認精確差額並保存稽核，保留原始權利；已使用、預占或結轉部分不能任意減除。 |

## 明細與確認視窗

指標排列、指標明細、裝置與年資特休明細視窗皆有獨立操作說明，可在視窗內開啟；按 Esc 或關閉返回原視窗。

### 指標排列與高度

八張卡保留固定資訊群組，可調整個人排列順序與顯示高度。

1. 逐列用向上／向下按鈕調整順序，選擇顯示高度並查看預覽。
2. 確認設定後儲存；關閉若有未存內容，可繼續編輯或捨棄。

- 設定只影響目前帳號的呈現，不改統計資料或其他管理者。
- 舊單項設定轉換為八個群組；請依遷移提示核對並保存。

### 指標明細與統計範圍

核對卡片的統計口徑、彙總與人員明細，再進入有權限的設定。

1. 七日卡可切換日期；待審卡可切不同審核階段。
2. 以人員關鍵字及部門縮小清單，查詢後核對總數與分頁。
3. 出勤統計範圍可選全部、在職、部門或手動人員；設定頁入口另以按鈕標示。

- 每日人數是當日不重複員工，跨日同一人可能出現在多日，不可直接相加當七日不重複人數。
- 待審依申請件數；正常打卡依人數，異常打卡含紀錄與失敗稽核，不能將不同口徑相除當出勤率。
- 沒有權限顯示不可查看，不應當作零；篩選不修改原始紀錄。

### 裝置明細與解除確認

查看一位員工的裝置及最近使用情形，只解除已核對的指定範圍。

1. 先核對裝置名稱／ID、平台、綁定與最後登入時間、IP 及 GPS 資訊。
2. 解除此裝置只處理單一裝置；危險操作區的解除全部只限這位員工。
3. 確認頁列出受影響裝置；勾選影響確認，全部解除另需輸入該工號，再按確認解除。
4. 返回裝置清單或關閉不執行解除；確認期間名單已變動會拒絕，重新檢查後再操作。

- 解除綁定不刪除打卡歷史，且不會清除全體員工。
- IP、GPS 及最後使用時間是當時記錄，不表示裝置現在的位置。

### 遠端打卡個人明細

查看該人最近兩週的完整遠端打卡紀錄。

1. 核對期間、時間、上下班類型、考勤狀態與裝置。
2. 逐項查 GPS／精度與風險資訊，關閉回到人員彙總。

- 風險標記供查核，不直接認定違規或計算薪資。
- 紀錄數、出勤日數及裝置數有不同口徑。

### 個人特休計算與來源明細

唯讀查看授權範圍內的已入帳權利、計算快照與異動。

1. 核對年度及員工。
2. 展開來源權利與計算過程，查看起算日、資格日、法定日數、分段比例、分數原值及進位差額。
3. 查看使用、預占、結轉與調整流水；關閉返回原頁。

- 員工只看本人，代辦主管只看已明確授權員工，均不能從此視窗調整額度。
- 來源快照保留當時規則，不因後續制度版本而被改寫。
- 不同來源期限與工時可能不同，應以各來源精確明細核對。

本人由員工工作台「請假申請」的假別餘額區進入「查看年資特休計算明細」。代辦人員在「主管代辦」先選已授權員工，再按「查看代辦員工特休明細」；未選人員會提示選擇，不默認開啟第一位。管理者亦可從權利總覽逐人開啟。

## 清單列操作補充

- 編輯：把所選項目載入表單，儲存前不異動原資料。
- 刪除／清空歷史：先確認所屬資料與影響範圍。
- 清空／重設表單：恢復新增／初始狀態並捨棄未儲存的輸入，不刪除已儲存資料；清除篩選只重設查詢條件。
- 核准／駁回：先核對對象、票權與備註；必審案件需按全部指定主管的進度判定。
- 修正／作廢：限具權限的適用紀錄；修正維持同一單號並保存稽核，作廢記錄原因。
- 啟用／停用：切換設定是否生效，不刪除歷史。
- 分頁：上一頁／下一頁只切資料視窗；總筆數與目前頁筆數不同。
