# 週六加班條件複核操作說明

適用版本 v1.51.0（2026-11-12）

## 設定適用範圍

週六加班條件複核預設停用。具設定權限的管理者在「管理者工作台 → 主管指定 → 條件複核」開啟設定，設定生效日期、適用假別、主複核人及選填的備援複核人。主備須為不同員工。確認設定與受影響日期後，填寫原因並儲存。如果資料已變更，請重新讀取再確認。身份模擬只可查閱。

系統以台北日期判定。加班與生效日當天或之後的週六有重疊時，檢查同一員工在該週週一到週五是否有適用假別的申請，且與出勤日曆的工作日正常班時段重疊。正常班分為 08:20–12:20 與 13:00–17:00。待主管、待管理部複核及已核准請假均可作為複核依據。舊假單無法精確確認實際請假時段時，請複核人核對原單。

## 申請與額外複核

本人申請、主管代辦及紙本加班補登送出前，先核對條件複核預覽。命中條件時會列出請假日期及複核人選，依畫面確認後送出。若期間或請假資料在確認前變更，重新預覽再送出。

線上加班先經原主管審核，再轉入「待額外複核」。複核人以本人帳號進入員工工作台的週六加班複核清單，核對依據後填寫意見，確認核准或駁回。本人、代辦人與已核准本案的第一關主管須迴避。主複核人不適用時才由備援接手。若沒有符合條件的複核人，仍可確認送出，案件等待具設定權限的管理者核對人選並改派。改派會保存原因與歷程。

## 補複核及外部資料核對

已觸發的案件保留當時的規則與原核准紀錄。即使停用或變更設定，或原觸發請假已撤回，既有待複核案件仍須完成複核，或依正式撤回、作廢流程結案。

已核准加班後續若命中條件，可能轉為待額外複核並標示補複核。原主管核准與額外複核歷程保留，供人員對帳。待額外複核案件在日曆及本人出勤列為待審，核准後才列入已核准加班。

若原核准結果已匯出、被外部系統讀取或進入出勤結算，請依補複核標示查明影響範圍，將本次結果與外部匯出、薪資或結算紀錄比對，依既有流程人工更正並保留對帳依據。先前已產生的檔案或外部紀錄仍須逐筆核對。
